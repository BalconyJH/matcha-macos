# Support

Use [GitHub Issues](https://github.com/BalconyJH/matcha-macos/issues) for reproducible Matcha bugs and
protocol compatibility problems. Include the Matcha version and build number, macOS version, Mac
architecture, selected protocol and transport, peer framework version, and reproduction steps.

Before attaching exported logs or screenshots, remove access tokens, message content, raw protocol
payloads, local file paths, and personal data.

Questions or defects specific to a NoneBot adapter belong in that adapter's repository. Problems in
the original Vue/Tauri implementation belong in the
[upstream Matcha repository](https://github.com/A-kirami/matcha).

Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
